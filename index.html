Research

One model, many surveillance jobs.

A modular, configuration-driven vision model for surveillance

Most surveillance models are trained for one job, and a new job usually means a new model. My thesis builds a large vision model made of modules that are chosen through configuration, so one base model can be pointed at different tasks.

Full title: “Towards Unified and Adaptive Perception: Designing Large Vision Models with Modular Deep Learning Architectures for Dynamic Surveillance Environments”

  • PPE compliance: checking whether people on site wear the protective equipment they should.
  • Incident detection: spotting fire or explosions, weapons, and a person on the ground in single images.
The methods, in plain English
  • LoRA fine-tuning: adapt the large model to a new task by training a small add-on instead of the whole model.
  • Out-of-distribution tests: check the model on images that look different from its training data, because real cameras rarely match the lab.
  • Shortcut checks: make sure the model learns the real signal and does not lean on an easy cue such as the background.

Configurable real-time anomaly detection

One system for monitoring different closed environments. YOLO finds the people in each frame, DeepSORT follows each person from frame to frame, and FaceNet recognizes faces.

A configuration file decides which of these run, so setting up a new place means editing settings, not code.

A live demo is not public. I'm glad to walk through the design in an interview.
